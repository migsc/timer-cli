# Bundled alarm

`alarm.wav` is an original synthesized sound created for the migsc/timer-cli
fork. Copyright 2026 timer-cli fork contributors.

Licensed under the Apache License, Version 2.0; the complete license is included
in `LICENSE` in this directory. Redistribution and modification are permitted
under that license. There are no third-party recordings or samples.

Source: https://github.com/migsc/timer-cli/blob/main/scripts/generate_alarm.py

Recreate it from the repository root with `python scripts/generate_alarm.py`.
The file is a 3.6-second, mono, 44.1 kHz, 16-bit PCM WAV: six pulses alternating
between 880 Hz and 1320 Hz, with a second harmonic and smooth fades.
